# Survey · Formulário de pesquisa

Formulário de pesquisa responsivo feito só com **HTML e CSS**, durante os estudos de desenvolvimento web no freeCodeCamp.

> 🇺🇸 Responsive survey form built with plain HTML and CSS while studying web development on freeCodeCamp.

## O que tem

- Campos de texto, e-mail e data com validação nativa do navegador (`required`, `type="email"`)
- Listas de seleção, botões de opção, caixas de marcação e área de comentários
- Layout centralizado com estilo próprio em `style.css`

## Como ver

Abra o `index.html` no navegador. Não precisa instalar nada.
